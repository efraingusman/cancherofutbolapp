Cómo obtener los links
MercadoPago
1. Entrá a mercadopago.com.uy
2. Tu negocio → Cobros → Suscripciones
3. Creá un plan para cada precio
4. Copiá el link de pago generado
Stripe
1. Entrá a dashboard.stripe.com
2. Payment Links → Crear link
3. Configurá precio recurrente
4. Copiá el link generado
